# Security policy

Do not report sensitive security issues by opening a public issue containing exploit details, secrets, private infrastructure information, or personal data.

For now, contact the repository maintainers through the private security-reporting mechanism configured for the GitHub repository. Maintainers should enable **GitHub Private Vulnerability Reporting** before accepting external contributions.

This policy covers repository-maintained scripts, CI workflows, and configuration examples. Vulnerabilities in third-party runtimes, container images, model servers, drivers, models, or dependencies should normally be reported to the relevant upstream project as well.
